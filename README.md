# travel-guide-builder

旅行攻略工程化生产与迭代的可复用 Skill：把一次出行从「需求 → 双源调研 → 排程 → 图文成稿 → 验证 → 发布」做成标准流水线。核心特点是**内网同事红黑经验打底 + 小红书强关联实拍 + 单文件 HTML「粗中有细」行程图册**。

## 目录结构

```
travel-guide-builder/
├── SKILL.md                       # 入口：七阶段流程 + 长期硬约束 + 索引
├── references/
│   ├── 01-intel-collection.md     # 内网红黑采集 + 小红书模拟人工 SOP + 双 AI Gate 图库
│   ├── 02-itinerary-method.md     # 排程方法论（航段倒推/班期/体力作息/多方案）
│   ├── 03-html-contract.md        # 单文件 HTML 图册契约（简洁/详细双视图、响应式）
│   ├── 04-verify-release.md       # 验证闭环、版本快照、扁平英文 URL 的 Pages 发布
│   ├── 05-lodging-acquisition.md  # 住宿 MCP 采集 + 只读酒店/民宿选型页
│   └── 06-overview-poster.md      # 区域总览海报流水线（多区域拆图、固定视口渲染、压缩嵌入）
├── assets/
│   ├── html-scaffold.html         # 行程图册起步骨架
│   ├── poster-scaffold.html       # 总览海报起步骨架（?r= 多区域切换）

└── scripts/

```

## 能力概览

- **双源情报**：内网旅游群/同事文档提炼红榜（推荐）与黑榜（避坑）；公开渠道核验签证、班期、营业时间等易变事实。
- **小红书采集**：浏览器模拟人工点击、读正文+评论、双 AI Gate（先审帖、再逐张审图）保证图片与点位强关联，不跨点挪用、不拿泛图凑数。
- **逐日排程**：航段倒推、不连续飞行、体力曲线、作息约束、同酒店连住寄存、当地团型按「高光点停留时长」选型、多方案。
- **单文件 HTML 图册**：默认简洁版、一键切详细版；Leaflet 航图与逐日小地图、区域总览海报（压缩图嵌入简洁版）、时间轴与地图编号对应、实拍点击弹窗、航段总览、红黑榜、本地实用信息、预定专栏、备选池、重点专栏、风险应急、启程倒计时；手机竖屏适配。
- **住宿选型**：授权 MCP（Trivago / Airbnb 等）采集报价与高评民宿，输出只读的酒店/民宿两组选型页。
- **验证与发布**：每轮浏览器 DOM 校验 + 截图目检；版本快照；扁平、全英文 URL 的 GitHub Pages 发布。

## 使用

将本目录放入 Agent 的 skills 目录（名为 `travel-guide-builder`），在需要做旅行/自由行行程规划、HTML 行程图册、沉淀同事旅游红黑经验或采集小红书旅行实拍时即会被加载，按 `SKILL.md` 的七阶段推进。

> 个人旅行自用，方法沉淀；请勿转载、禁止商用。
