# 05 · 住宿采集与住宿选型页（MCP 优先 + 只读展示）

住宿信息分两层采集，再汇成一个**只读**选型页帮用户做订房决策；不做可编辑工作台、不做勾选对比。

## 1. 采集通道优先级（能用官方/授权 MCP 就不碰网页风控）

| 对象 | 首选通道 | 说明 / 坑 |
|---|---|---|
| 酒店聚合报价 | **Trivago 官方远程 MCP** | 免 key、无风控，可一次拿到多 OTA 报价/评分/评论数/首图；作为酒店报价主力 |
| 民宿 / Airbnb | 社区 `@openbnb/mcp-server-airbnb` | 启动须带 `--ignore-robots-txt`；软限流，每次调用间隔 25-30s；拿 Guest favorite / Superhost、评分、评论数、晚价 |
| Trip.com | 官方 MCP（需 affiliate key） | 无 key 不可用时，用 browser-use **模拟人工**到 Trip 页面补价与 hotelId 深链，不要编 hotelId |
| Booking | 无官方 MCP | 由 Trivago 聚合得到，不单独爬 |
| Agoda / 其它 OTA | Trivago 聚合 | 同上 |
| 小红书口碑/实拍 | **无 MCP**，只能 browser-use 模拟人工 | 走 references/01 的 SOP：搜索→点帖→读正文+评论→双 AI Gate；评论区必看 |

- 授权 MCP 是用户认可的「非爬虫」替代；**任何脚本直拉 HTML/CDN 都算爬虫，禁止用于小红书**。
- 报价、评分、评论数必须带**采集日期**；价格会变，页面上固定写「YYYY-MM-DD 采集值，下单前以平台实时价为准」。
- 所有 MCP/人工报价落一份 `lodging-data/quotes_summary.json`，它是价格的**唯一权威**，页面只渲染它，不在 HTML 里凭记忆改价。
- 口碑文字落 `lodging-data/xhs_reputation.json`（样本量、高频好评、高频差评、区域共识、「无专属帖」清单）。

## 2. 强关联防串店（和景点图同等级别）

- 按「**酒店全名 + 城市**」专搜，泛菜品/泛客房/泛海景图一律不算本店图；餐厅同理要见门脸/店名/同帖指名。
- 名字相近的不同店必须分开建卡（例：Hotel Uyut ≠ Mildom；Holiday Inn Almaty ≠ Holiday Inn Express；同城两家 Holiday Inn Aktau 分店勿混）。
- 某家确实搜不到专属实拍时，**如实标注「小红书专属实拍极少」并留空**，不拿同名连锁/别家图冒充。
- 民宿优先「评价好的」：Airbnb Guest favorite/Superhost + 评分≥4.8 且评论数有意义，再叠加小红书高评民宿交叉验证。

## 3. 只读选型页契约（assets/hotel-picker.html 为最新样板）

- 文件名用英文、放单一子目录：发布结构里是 `hotels/index.html`（见 04 的扁平发布），主攻略工具栏放入口。
- **只读**：没有 input/textarea/checkbox、没有新增/删除/导出/导入、不写 localStorage；保留城市 tabs、搜索框、排序、点击实拍灯箱放大。
- 分两个组渲染，判定 `isBnb = h.tier==='民宿'`：
  1. 「酒店 / 连锁与品牌公寓」
  2. 「民宿 / 公寓（Airbnb 与小红书高评）」
- 单卡字段：名称/英文名、区域、档次、适用晚次、参考价（无报价显「未采集到报价」+ 去查链接）、平台评分与评论数、标签 chips、🟥优势 / 🖤避坑、同事原话、小红书口碑（含「N 帖/N 赞」样本量）、实拍条、备注；`status:'out'` 作「避坑/不选」保留以防误订。
- 图片相对路径：选型页在 `hotels/` 子目录，引用根资源一律 `../assets/...`，返回主攻略链接 `../`。
- **内部采集 SOP（采集口径/字段说明块）不进发布页**——那是生产方法，交付前从页面删除。
- 卡片数据是内联 `SEED` 数组 + `MCP_QUOTES`；平台深链只在已查证时给真实 hotelId/房源链接，否则退化为「名称+城市」的平台搜索链接。

## 4. 采集节奏建议

1. 先用攻略结论 + 同事经验列候选清单（城市分区、连住晚次、避坑区域）。
2. Trivago MCP 批量补酒店报价/评分/首图；Airbnb MCP（带间隔）补高评民宿。
3. 缺口（需 key 的 Trip、特定分店）用浏览器人工补。
4. 小红书按店名专搜补口碑与强关联实拍，双 AI Gate 入库，更新两份 json。
5. 渲染只读页 → 浏览器验证两组数量、0 裂图、灯箱、城市筛选 → 随主攻略一起发布。
